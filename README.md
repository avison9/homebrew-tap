# homebrew-tap

Homebrew casks for tools published by avison9. Each is written here by the
tool's own release workflow (goreleaser) on every tagged release; nothing
in this repository is edited by hand.

```
brew install avison9/tap/cdclint
```

| cask | what it is |
|---|---|
| [cdclint](https://github.com/avison9/cdclint) | lint the contract between your database, your Debezium connector and your sink |
